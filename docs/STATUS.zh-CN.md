## 软件验证范围

- Type：223 项 Rust 通过、0 失败、11 忽略；core、四套 React 状态测试与 Windows/mobile 构建通过。移动端构建是演示壳验证，不代表原生手机产品可用。
- MSI 正式安装，EXE/DLL 与包内提取载荷一致；安装版只读 CLI 核对配套 FW/UI 身份通过。
- 官方内置浏览器的同一预览地址已能使用。浏览器是演示数据，不是真设备或安装版 GUI 证据。
- 固件沿用 FW1.1.18 / UI36。本轮精修未改固件；9493 个画面状态对比仅 34 个 About 状态版本文字变化的既有证据保留。

## 当前硬件问题

- EPD_RES 尚无已确认的 MCU 控制端，屏幕不能登记为就绪。
- 68K:68K 分压在满电 4.2V 时约为 2.1V，超出 1.8V ADC 测量量程；充电 PG/STAT 上拉尚待确认。
- 新板显示、触摸、声学、续航、升级断电恢复及完整会议链仍待实物。

## 使用限制

- 第一版使用宠物音效，没有语音对话或可交付的唤醒词功能。
- “先录后整理”指采集后再转写，不等于全部离线识别。云 ASR 会接收音频，云纪要服务会接收转写文本；需自行配置服务，费用和配额由提供方决定。
- Type 在线录音流程最多 43 分钟；设备录音默认 30 分钟，可选 15/30/60/不限时。设备设置、剩余连续空间或错误可能更早停止。“不限时”仍受容量约束；没有无缝连续分段能力。
- USB-C 在当前 PCB 上仅供电。六针用于初次安装和维护，正常日常使用不需要接调试线；不能把数据线插上视为已建立数据连接。
- 硬件尚未完成验收，不提供已经量产、正式发售、开箱即用或特定续航的承诺。
