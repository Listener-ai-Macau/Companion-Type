# Companion Android 0.1.124 可用候选

本批在 0.1.123 完整音视频导入链上增加手机图文备注：打开录音 → 备注 → 添加文字或 JPEG/PNG/WebP 图片 → 可选录音时间 → 保存。点击备注时间可回听，文字和图片可随当前资料库备份并恢复。备注为人工补充，不替代原始转写或 AI 事实，不会自动上传 AI。

导出时选择“补充与事项”：图文 ZIP 包含备注、时间、原图及离线网页，解压后打开“打开阅读.html”；Word、PDF、复制等文字格式保留文字、时间与图片名称，界面明确这些格式不嵌入原图。只输出当前勾选的内容。删除备注会移除其入口；归属原图保留至整条录音永久清除。

候选安装包 `Companion-Android-0.1.124-core-candidate.apk` 与公开测试资料备份 `Companion-public-notes-backup124.zip` 已分别保存到原私有草稿，下载回读字节一致。源码提交 `045e81c12f2246db69a54a55502afba339a68b18`，CI `42757217456`。完整构建、安装、使用、导出、恢复、原资料保护与远端收据见 `notes-delivered-result.json`。正式签名/发布及整机售卖资格仍按原任务门，不发布此工程候选冒充正式销售版。

限制：图片每张最多20MiB、80MP（边长24000以内），每条录音最多500条备注、每条文字4000字符；不支持图片OCR、PDF/Word文档导入或图片自动进入AI。手机此子范围已工程验证，Windows图片/时间上下文及其它原非模型任务继续开放。Owner验收没有由工程自行代签。
