Companion Type Windows third-party materials

ThirdPartyNotices.txt contains original notices and the component index.
ThirdPartyComponents.json records exact versions, declared license expressions, source URLs and checksums.
texts/ contains the original byte-preserved texts.
sources/ contains the exact unmodified cssparser, dtoa-short, option-ext and selectors crate archives used as corresponding public source. Extract each .crate as a gzip tar archive. These are upstream sources, not Denzic application source.

The scope is the locked active Windows normal Cargo input closure plus actual rendered frontend modules. Linker removal may reduce final code. Build-only tools, other target dependencies, OS-provided runtimes and optional unbundled models are excluded. This material does not represent a formal commercial/legal release approval.
